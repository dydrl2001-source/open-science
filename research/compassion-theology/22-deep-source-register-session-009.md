# 22. Deep Source Register — Session 009: 다중심성과 복음의 규범성

## A. 갈라디아서 2장 안디옥 사건
- 갈 2:11–14의 중심은 베드로의 명시적 교리 변경보다 이방인과의 식탁교제 철회.
- 바울은 이를 “복음의 진리를 따라 바르게 걷지 않음”(οὐκ ὀρθοποδοῦσιν πρὸς τὴν ἀλήθειαν τοῦ εὐαγγελίου)으로 판단.
- 최근 한국 연구(이우경, 2025)는 베드로의 행동이 의도와 별개로 이방 신자들에게 유대적 준수를 암묵적으로 강요하는 결과를 낳았고, 바울의 공개 책망을 공동체 정체성과 복음의 진리를 지키는 신학적 대응으로 분석.
- Cummins의 연구는 안디옥 사건을 십자가에 달리고 높임받은 그리스도 안에서 형성된 종말론적 하나님의 백성의 문제로 읽음.
- 주의: 안디옥 식탁의 정확한 음식 규정·성찬 여부·예루살렘 회의와의 연대는 논쟁적이므로 단정하지 않음.

## B. Stephen Bevans — contextual theology
- 모든 신학은 어떤 의미에서 contextual.
- translation, anthropological, praxis, synthetic, transcendental, countercultural 모델을 구분.
- 상황은 신학의 단순 포장지가 아니지만, context를 무비판적으로 승인할 수도 없음.
- countercultural model은 context 안의 anti-gospel 요소에 비판적으로 맞설 가능성을 보존.
- Whyte(2023)는 Bevans 모델을 contextualization 정도뿐 아니라 host culture/established church의 status quo에 대한 관계 축으로 재검토.

## C. Andrew Walls
- **Indigenizing principle**: 복음은 사람들이 실제 자신의 문화·언어·사회 안에서 그리스도인이 되도록 뿌리내림.
- **Pilgrim principle**: 복음은 동시에 모든 문화에 낯섦을 남기며 어떤 문화도 그리스도와 완전히 동일시되지 못하게 함.
- Müller(2013)는 두 원리가 단순 반대극이라기보다 실제 world Christianity에서 복합적으로 작동한다고 재평가.
- 연구상 사용: contextual ownership과 prophetic critique를 동시에 보존하는 이중 운동.

## D. Lamin Sanneh — translatability
- 기독교는 revealed language 하나에 묶이지 않는 번역 가능한 종교라는 논지.
- vernacular translation은 현지 언어에 성서적 권위를 부여하고 local appropriation을 촉진.
- 번역된 성서는 선교사의 통제를 넘어 현지 독자가 스스로 읽고 해석하는 결과를 낳을 수 있음.
- 한국 선교신학 연구(김완, 2025)도 사도적 메시지의 translatability를 현대 전도에 연결.
- 주의: 번역가능성이 모든 번역/현지 해석의 타당성을 보장하는 것은 아님.

## E. 규범성 문제의 작업 구별
1. **복음의 중심**과 **한 문화의 복음 해석**을 동일시하지 않는다.
2. 모든 상황신학은 contextual이지만 모든 contextual theology가 동일하게 타당한 것은 아니다.
3. 외부 비판은 자동으로 식민주의가 아니며, 현지 해석은 자동으로 진정성이 보장되지 않는다.
4. 판별은 단일 문화의 기준이 아니라 성서 증언, 그리스도 사건, 공동체 열매, 주변화된 사람의 결과, 세계교회의 상호 비판을 함께 통과해야 한다.
