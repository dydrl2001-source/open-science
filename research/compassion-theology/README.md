# 긍휼의 신학 — Open-Science 연구실

## 중심 질문
**긍휼은 이미 알고 있는 복음의 윤리적 적용인가, 아니면 복음과 하나님을 올바르게 인식하게 하는 신학적 인식 방식인가?**

이 프로젝트는 답을 전제하지 않는다. 오히려 성서 본문, 신학 전통, 철학과 사회과학의 대화를 통해 두 가능성을 경쟁 가설로 검증한다.

## 연구 원칙
1. 원문과 1차 자료를 우선한다.
2. 직접 인용, 해석, 추론, 잠정 명제를 구분한다.
3. 반례가 나오면 기존 명제를 보존하기보다 수정한다.
4. 약자/고통받는 자의 관점은 자동으로 참인 결론이 아니라 기존 보편성 주장의 사각지대를 시험하는 인식론적 위치로 다룬다.
5. 신학적 결론은 성서 주해와 그리스도론적·복음적 정합성을 다시 통과해야 한다.
6. 적용보다 먼저 인식 구조가 어떻게 변하는지를 묻는다.

## 경쟁 가설
- **H1 적용 모델**: 복음의 진리는 먼저 주어지고 긍휼은 그 진리의 윤리적 결과다.
- **H2 인식 모델**: 긍휼의 실천과 타자의 고통에 대한 응답은 복음의 의미를 더 정확히 인식하게 하는 조건이다.
- **H3 상호구성 모델**: 복음이 긍휼을 낳고, 긍휼의 실천이 다시 복음 이해를 교정한다.

## 현재 검증할 잠정 명제
> 기독교적 보편성은 위에서 모든 차이를 지워 얻는 동일성이 아니라, 배제된 자리에서 그 보편성이 실제로 누구에게까지 복음인지 검증될 때 더 충실해진다.
